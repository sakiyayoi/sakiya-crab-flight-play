# さきやのカニゲーム制作元

非公開の制作リポジトリ。カニ飛ばしとカスタムカニバトルを別のUnityプロジェクトとして保持します。既存のエビカニ判決とは別作品です。

## main の比較基点

|作品|Unityプロジェクト|保存した確認済み版|
|---|---|---|
|カニ飛ばし|`games/flight/crab-flight`|anatomy1-exit1-final01（配備v4の制作元）|
|カスタムカニバトル|`games/battle/crab-action`|telegraph-r1-ready（双方の攻撃予測線）|

Unity 6000.3.23f1 / Built-in Render Pipeline。各プロジェクトを個別に開き、EditorのBuildFlight / BuildActionからビルドします。隣のweb-templateは実行ページと操作・音のラッパーです。生成済みWebGL、Unityキャッシュ、実行ログ、会話、認証情報は含めません。

以前の制作結果からのスナップショットをここから履歴化します。過去のGit commitや制作日時を復元した履歴ではありません。FBX内のローカルユーザーパスはメタデータだけ除去し、形状・関節・アニメーションと.meta/GUIDを保持しています。

動作確認と面白さ・本人採用は別です。飛ばしの再投距離差、バトルの一部装備で連打勝利、写実性、物理iPhone・実聴は残件です。mainからのGit pushで試遊ページを自動配備する設定はありません。

## 作業

新しい素材・コードは短命branchとdraft PRに保存し、統合担当が順に同版を検証します。Scene・Prefab・ProjectSettingsの共有編集は単独所有。未検証統合をmainへ混ぜません。素材の条件はThirdPartyNoticesを参照してください。
