# カニとばし — r5 試遊版

10秒スワイプで回して、最後に弾いて発射。実際の衝突・連鎖破壊から有限の回転力を前進・回転・跳ねへ配分します。着地操作なし、タップ再投。音は操作で開始し、ミュート・音量・動き軽減があります。

r5は実回転枠を約22→28回転/秒へ広げ、後半の街と対象を延長し、実飛距離を大きく表示します。この比較ではカスタム入口を隠し同じ形状で遊びます。破壊済みの金属・木片が主役を隠す時だけ局所透過します。

制作途中の試作品で、完全版・本人採用ではありません。固定条件で飛距離・二次破壊が増えましたが、高角度では低い物を飛び越して総破壊数が減る代償があります。全入力で連鎖3を保証しません。物理iPhone、実機性能、実聴、本人の新候補の手触り・採用は未確認です。
