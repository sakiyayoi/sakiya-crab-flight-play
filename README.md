# カニとばし — r4 試遊版

10秒スワイプして回転力をため、最後に弾いて発射。実際に壊した物への接触で有限の回転力を前進へ使います。着地操作なし、結果からタップ再投。音は操作で開始、ミュート・音量・動きを抑える設定があります。

r4は破壊済み金属片が甲羅・ハサミ近傍への視線を遮る場合の透過表示を追加した試作品です。物理・配置・得点ルールはr3のままです。全ての障害物を透かす機能ではありません。

未採用・制作途中。固定4入力では実二次破壊3でしたが、別の通常スワイプでは2でした。通常入力で3を保証せず、完成や面白さの評価と区別します。物理iPhone、実機性能、実聴、本人の手触り評価・採用は未確認です。
