# カニとばし r6 街・甲羅・衝撃 改良試作

10秒スワイプで回して、弾いて発射。壊して加速し、自動着地からタップ再投します。r5の物理・408配置・13コライダー・有限回転エネルギーは保持。実飛距離表示に倍率はかけません。カスタム入口の非表示は可逆のままです。

甲羅と掌の実頂点を外形範囲内で作り込み、11部位の取付位置・UV・indexを維持しました。腹側に弱い補助光。街の建物へ窓枠・庇・軒を9,624三角形/4batch追加（非接触背景）。衝撃VFXは接触法線と実際の飛翔速度方向へ展開。音は既存39オリジナルWAV、ミュート・音量・動き軽減を保持。

27構成の部位契約、31走行と照明修正4走行は保存済み。物理主要4ファイルはr5と同SHA、固定入力の数値/接触列は比較した範囲で一致。これは全入力の連鎖3や全環境の物理決定性を保証しません。高回転入力はパラメータproxyで、収録スワイプ再生ではありません。

制作途中の未採用試作で、完全版ではありません。物理iPhone、実機性能、実聴、本人の手触り・採用は未確認。終点の背景空白、自己遮蔽、透過破片の違和感、全構想の商業施設→国→宇宙などは残ります。既存r5はGit履歴76df04e0aba6547b70eebf8b57d1c5d83afa64b2へ保持。
