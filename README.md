# カニとばし r10 — 比較試作

10秒間よこスワイプで回し、上へ弾いて発射。結果から同条件再投、または回し直せます。音と動きを抑える設定あり。

既知の弱入力で起きた床安全停止を限定修正。遠方600–1300mに新しい港市場・高架沿いの試作地域と接触対象を追加。格子架台・ガラス什器、驚く人と飛び立つ鳥を追加しました。地域名と細部は制作上の候補です。

未完成・本人採用前。すべての入力で連鎖3回や床のゼロ食い込みは保証しません。約0.401mの瞬間的食い込みが診断時に残りました。ガラス什器は描画確認までで自然飛行の接触未確認。遠方の平板な質感や密度には改善余地があります。実聴、物理iPhone、実GPUフレーム計測は未確認。

成長・コインと音/動き設定は既存保存を使用。飛距離は新しいルールの別記録、r9記録は保持します。追加課金・広告なし。公開は試作品の共有であり完成判定ではありません。
