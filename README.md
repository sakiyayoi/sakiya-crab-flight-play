# カニとばし r9 — 世界と天井の比較試作

10秒スワイプで回し、上向きに弾いて発射。着地操作は不要。結果からタップで再投。音量・ミュート・動き少なめあり。

レストランの背面設備、商業施設のガラス回廊、オフィス街の塔を分け、旧背景との重なりを整理。既存13破壊物の枠・面・凹凸を実際のIntact/Fractured/Shardへ接続し、元ピボット・Colliderを維持しています。

任意コイン成長は候補のまま。打ち出し速度+4%/段階に加え、level2以降は十分な実衝撃で天井が壊れた後、上方向へ抜ける比較案です。低レベルでも天井の一部は壊れますが上向きの勢いを吸収します。上部に看板・外装パネル・設備の18接触を配置。常に全て壊せる保証はありません。

Mac Chromeの実スワイプは未強化141.2856m/22破壊/実二次6。同再投と軽減再投も同じ結果・各51coin。ゲーム内30+50coinでlevel2へ上げ、同じ発射は232.4431m/22破壊/実二次7・天井上抜けになりました。初速も変わるため、全距離差を天井機能だけの効果とはしません。

固定入力の地上4条件はr8の物理指標を保持。独立レビューで背景の隠れと高空の主役縮小を修正しました。全体の写実性・地域の深い遊び分けは未完成です。

既知の弱入力では床貫通の安全停止が残り、その投球は記録・コイン対象外です。以前の公開412.7→470.5m差は元の受理入力が未保存で原因未確定。今回の同条件一致を全ての再現性保証へ一般化しません。全入力の実二次3は保証しません。

物理iPhone・実聴・実GPU FPS・本人採用は未確認。完全版は制作中。外部課金・広告・新認証はありません。旧r8はGit履歴で復元できます。

動画は同版の実再投をUnity canvasと原出力音で収録。DOM HUDとマイクは含みません。ZIPはWebGL配布候補で、HTTP環境で実行します。公開先は https://sakiyayoi.github.io/sakiya-crab-flight-play/ です。
