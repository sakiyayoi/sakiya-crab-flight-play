# 動画で見るチェック（CHECKLIST.md）

使う動画：`record_compare.js` の 3 本（マシマシ `M`／ふつう `F`／オフ `O`、同じ入力：強 100・40°）と通し動画 `P`。
リリーが先に見て「秒」と「リリー」を埋める（◯ か ✕）。**リリーの列が全部 ◯ で、秒が全部入っていないとゲートの G-CHECKLIST が ✕。**
「マツリ」の列はマツリが書く（ゲートは見ない）。「秒」は `M 0:03.2` のように動画の記号と時間。複数あれば `、` で区切る。
ゲートの記録（`compare/*_fx.json`）で出たことは確かめてあるので、ここで見るのは「目で見てそう見えるか」。
