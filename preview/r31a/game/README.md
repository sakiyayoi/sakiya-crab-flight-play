# カニとばし 試遊版 kani-v0.6-impact-r31a

未合格の比較試作です。完成版・本人採用版ではありません。
スワイプ／タップで10秒回し、向きと勢いを決めて発射。壊した物を巻き込みながら進み、結果からもう一投できます。PCはEnterでチャージ／発射、飛行中はSpaceで着地プッシュも操作できます。

## ローカルで遊ぶ
ZIPをフォルダへ解凍し、そのフォルダで `python3 -m http.server 8000 --bind 127.0.0.1` を実行。WebGL対応ブラウザで http://127.0.0.1:8000/ を開きます。HTMLの直接ダブルクリックではWASMを読み込めません。音は初期オフです。音・動きから音量、演出、揺れを調整できます。
ブラウザを閉じる前の記録は同じURL／同じブラウザへ保存します。ローカル試遊とオンライン試遊の保存は別です。既存の正式ページとは記録を分離しています。

## この試作の変更と未確認
UI補修ui1：縦画面の経路帯をスコアの直下へ移し、再投ボタンまでの空間にカニを見せます。WASMはd4ff509のままです。元の全検査は35PASS/1FAIL（弱55・55度左の短距離停止）、UI補修後の全40投は再実行していません。強入力40度右も6.26mに留まる記録があります。

中心を空けた太い命中形と大小差のある材質片、結果画面の主役を避ける配置へ変更。Collider簡略化候補に反転による退行が出たため、その変更は不採用として基準r30の形状を保持しました。飛距離や衝突結果は旧版と変わり得ます。残る一時的な床侵入、Colliderの見た目との差、全区間の反復、実iPhone、実聴、本人の手触り判断は完成認定していません。正式ページは変更していません。
