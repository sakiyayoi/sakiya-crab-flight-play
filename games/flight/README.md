基準 r15-ui1 `37ee076a00887a31fbe24dfdeabb2a924ef3f2d4`。公開r15は変更していません。未採用の比較候補で、完全版完成や本人の手触り評価を主張しません。

10秒スワイプの入力仕事を6画面幅/秒で切り捨てず、超過分を圧縮して有限の回転エネルギーに加えます。剛体回転は従来28rpsから最大40rpsへ軟らかく近づき、入力要求値と実剛体回転数を別に保持します。追加の回転運動エネルギーは実入力由来の在庫から一度支払い、破壊数や加速回数に加算しません。技術限界を撤廃した無限物理ではありません。

回転端が床へ入る前の実支持点速度で、既存最大8回の細分化を開始します。停止閾値-0.45m・Collider・質量・反発・資源係数は保ちます。必要3入力では床安全停止を観測しませんでしたが、全入力の床問題解消ではありません。強35度は旧3220mから2312.5mへ短縮し、遠方進行との両立は残件です。

統合した候補は、9区間の描画専用造形、材質別破片、姿勢と実回転軸を読む軌跡、最大105ms/クールダウン/有限停止予算のヒットストップ、終端の局所引きカメラと実破壊位置の全経路帯です。通常/軽減で同じ標準入力の距離1071.4315m・38実破壊・二次11・物理時刻が一致。結果のPause・剛体固定・即再投をNative driverで確認しています。気持ちよさの採用をテスト点数で決めていません。

室内モールの天井・3層回廊・エスカレーター・ガラス店舗・館内床・陳列ケースを統合。看板の未破壊面・宇宙背景の明暗差・港/郊外ベンチの表面差も修正しました。ケースのガラス風表示に旧wood/wall/metal等の物理材質分類が残り、材質固有の音/破片との整合は残件です。背景回廊は描画のみで、新しい上階の衝突経路を実装した主張ではありません。
